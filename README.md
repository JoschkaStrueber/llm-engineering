# LLM Engineering

Interactive lecture guides for *LLM Engineering*, a 14-week graduate course at the University of
Tübingen (Bethge Lab), winter term 2026/27. Students build a production-style LLM training
framework from scratch.

**Read the lectures at https://llm.strueber.dev.** New lectures appear as the term goes on.

This repository holds the built site only. It is published from the course's source repository.
